# Task Tracking Mini-System

## Description
This project is a practical mini-system for task tracking, developed for Lab Activity 3. It utilizes Object-Oriented Programming (OOP) concepts by implementing two related classes: `Task` and `ProjectTracker`. 

## Required Tools
* Visual Studio Code
* Python Environment

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open a new Integrated Terminal (`Ctrl` + `~` or **Terminal > New Terminal**).
3. Ensure you have a Python environment activated.
4. Execute the script by running: `python project_tracker.py`
5. The terminal will automatically output three meaningful test cases demonstrating task creation, status display, and status updates.
